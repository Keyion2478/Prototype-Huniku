# Huniku - Prototipe Aplikasi Properti & Layanan Warga

Prototipe interaktif antarmuka aplikasi manajemen dan layanan perumahan terpadu berbasis web modern (Bandar Lampung).

## 🚀 Fitur Utama

1. **Katalog Unit & Reservasi Anti Double-Booking:**
   - Filter cluster dan tipe rumah (LB/LT, harga, promo DP).
   - Sistem hold kuncian 15 menit real-time untuk mencegah perebutan kavling yang sama.
   - Pilihan skema pembiayaan (KPR Bank, Cash Keras, In-House Syariah).

2. **In-App Live Chat & Lampiran Multi-Media:**
   - Obrolan agen resmi dengan status unread dot & balasan cerdas.
   - Menu lampiran (Berkas PDF KPR, foto bukti bayar, bagi lokasi GPS titik temu survei, kamera lapangan).

3. **Portal Pengaduan & Layanan Warga:**
   - Dashboard status retensi garansi developer (142 hari).
   - Formulir lapor kerusakan fisik fasilitas kavling dengan preferensi jadwal kedatangan teknisi (hari kerja/weekend/jam kustom).
   - Tombol chat dua arah langsung dengan admin pengelola & teknisi spesialis (Air, Bangunan, Fasum) di setiap kartu tiket.

4. **Master Desk Admin Developer & Estate:**
   - Bilah navigasi sidebar 5 modul terpadu.
   - **Site Plan Denah Peta Interaktif:** visualisasi blok kavling yang dapat diklik langsung untuk mengubah status (Tersedia, Dipesan, Terjual, Sita Bank).
   - **Antrean Verifikasi Booking:** validasi berkas KPR calon pembeli & tombol sahkan unit menjadi Terjual (*SOLD*).
   - **Disposisi Teknisi & BAP:** penugasan personil lapangan, chat langsung dengan warga, dan penerbitan lembar Berita Acara Pengerjaan resmi.
   - **Log Riwayat Audit:** pencatatan rekam jejak aktivitas sistem secara real-time.

## 🛠️ Teknologi

- **Frontend:** HTML5 Semantik, Vanilla CSS3 (Custom Properties & Responsive Design), Modern Vanilla JavaScript (ES6+).
- **Penyimpanan Data Prototipe:** Browser `LocalStorage` persistent state management (berfungsi penuh di cloud tanpa butuh database server backend).
- **Dependencies:** Zero external dependencies (*Pure Static Web*).
